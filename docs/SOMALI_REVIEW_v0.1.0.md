## Employment-description templates (Somali) — `resources/lang/so/templates.php`

Tokens `:role :organisation :region` are filled in at generation time.

1. `Jagada :role ee :organisation, oo gudanaya hawlaha aasaasiga ah ee gobolka :region.`
2. `:role ka tirsan :organisation, mas'uul ka ah hawlaha maalinlaha ah ee :region.`
3. `Xilka :role ee :organisation, taageeraya hawlaha hay'adda gobolka :region.`
4. `Shaqaale :role ah oo ka tirsan :organisation, isuduwaya hawlaha gobolka :region.`
5. `Ahaan jagada :role ee :organisation, ka qaybqaadanaya fulinta barnaamijyada :region.`
